  FIRST TIME SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  When you click the button for the FIRST TIME, you'll see:
  
  ╔════════════════════════════════════╗
  ║  🔒 Set Admin Password             ║
  ╠════════════════════════════════════╣
  ║                                    ║
  ║  New Password (min. 6 chars)       ║
  ║  ┌──────────────────────────────┐  ║
  ║  │ Type password here...        │  ║
  ║  └──────────────────────────────┘  ║
  ║                                    ║
  ║  [ Set Password ]   [ Cancel ]     ║
  ║                                    ║
  ╚════════════════════════════════════╝
  
  STEPS:
  1. Type a password (at least 6 characters)
  2. Click "Set Password"
  3. ✅ DONE! Admin panel opens automatically
  
  ⚠️  IMPORTANT: Remember this password! No recovery option.

  IMPORTANT ACTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  📥  EXPORT DATA (Top toolbar)
      → Downloads backup file: portfolio-backup-YYYY-MM-DD.json
      → Do this WEEKLY for safety!
  
  📤  IMPORT DATA (Top toolbar)
      → Upload backup file to restore data
      → Great for moving between devices
  
  💾  SAVE ALL (Top toolbar)
      → Force-saves all changes
      → Refreshes frontend automatically
  
  ⚙️  RESET PASSWORD (Top toolbar)
      → Change your admin password
      → Requires confirmation
  
  ✕  CLOSE ADMIN (Top toolbar)
      → Returns to portfolio
      → Changes already saved

  FIRST 5 THINGS TO DO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Click the ⚙️ button (bottom-right corner)
  2. Set your admin password
  3. Click "Export Data" to create first backup
  4. Browse all 11 tabs to explore
  5. Update Personal Info tab with your details
  
  Time needed: 10 minutes

  SAFETY REMINDERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅  Export backups weekly
  ✅  Store backups in cloud (Google Drive, Dropbox)
  ✅  Use a strong password (6+ characters)
  ✅  Remember your password (no recovery!)
  ✅  Test changes before sharing portfolio
  
  ❌  Don't share admin password
  ❌  Don't upload images over 2MB
  ❌  Don't clear browser data without exporting first

  Can't find the button?
  → Look at bottom-right corner of page
  → It's a blue pulsing circle with ⚙️
  → Try keyboard: Ctrl+Shift+A
  
  Forgot password?
  → Use "Reset Password" on login screen
  → Or clear browser localStorage (loses data!)
  → This is why regular exports are crucial!
  
  Changes not saving?
  → Click "Save" button in each section
  → Click "Save All" in top toolbar
  → Check browser console for errors
