## 🆘 **TROUBLESHOOTING**

### **Can't upload image?**
- Check file size (must be under 2MB)
- Verify format (JPG, PNG, GIF, WebP)
- Try different browser
- Clear browser cache

### **Changes not saving?**
- Click "Save" button in each section
- Check browser console (F12)
- Ensure localStorage enabled
- Try "Save All" in top toolbar

### **Page not showing?**
- Check Pages Manager - is it enabled?
- Refresh browser (F5)
- Check data export to verify

### **Image not displaying?**
- Verify image uploaded successfully
- Check Media Manager for image
- Copy correct URL
- Try re-uploading
