## **SAFETY TIPS** 🛡️

### ✅ **DO:**
- ✅ Export backups weekly
- ✅ Use a strong password (6+ characters)
- ✅ Store backups in Google Drive/Dropbox
- ✅ Test changes before sharing portfolio
- ✅ Keep this guide bookmarked

### ❌ **DON'T:**
- ❌ Share your admin password
- ❌ Upload images over 2MB
- ❌ Delete all content without backup
- ❌ Clear browser data without exporting first
- ❌ Forget your password (no recovery!)

## **COMMON QUESTIONS** ❓

### **Q: Where is my data stored?**
A: In your browser's localStorage (locally, not on a server)

### **Q: Will I lose data if I close the browser?**
A: No! Data persists until you clear browser storage

### **Q: Can I access from multiple devices?**
A: Yes! Export on one device, import on another

### **Q: What if I forget my password?**
A: Use "Reset Password" button in login screen (but you'll need to set a new one)

### **Q: How do I update my portfolio content?**
A: Open admin → Edit → Click Save → Close admin to view changes

### **Q: Are changes instant?**
A: Yes! Save in admin → Changes appear on portfolio immediately
